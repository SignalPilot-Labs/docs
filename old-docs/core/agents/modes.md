Modes
Choose the right level of control and automation

SignalPilot offers different modes of interaction so you can decide how much control to give the AI over your notebook. Each mode balances automation and manual oversight differently, letting you pick the workflow that fits your style.

Agent Mode
Maximum automation – the AI automatically manages context and generates, edits, and execute cells end to end.

Best for: running full analyses with minimal manual intervention.

The agent builds plans, executes them, and updates the notebook as it goes.


Prompt: Download and plot SPY data for the last 5 years.
Hands-On Mode
Shared control – you decide what context the AI can access and approve changes cell by cell.

Best for: users who want AI assistance without giving up fine-grained control.

The AI suggests code, edits, or plots, but you approve what gets added or executed.

Ask Mode
No notebook changes – the AI answers questions about your notebook without modifying it.

Best for: exploration, explanations, and learning.

Examples: ask what a piece of code does, request a summary of outputs, or get debugging advice without altering your cells.


Switching Modes
You can switch modes anytime using the mode selector in the bottom-right corner of the notebook interface.


FAQ
Q: Which mode should I start with?
Start with Agent Mode for fully automated workflows. If you prefer more control, switch to hands-on mode.

Q: Can I change modes during a session?
Yes. You can switch modes at any point—SignalPilot will adapt immediately.

Q: Does Ask Mode use my data?
Yes, it uses the notebook state to answer your questions, but it does not modify cells.

Q: Is Agent Mode safe?
Yes. SignalPilot shows you the plan before execution. You can always stop, edit, or roll back changes.

Q: Can I restrict what context the agent sees?
Yes. In Hands-On Mode, you decide what data and cells are shared with the AI.
