Connecting a Database to SignalPilot

SignalPilot makes it simple to connect your databases so you can start working with your data right away. We currently support the following databases:

PostgreSQL

MySQL

Snowflake

To get started, open the Database Menu in your SignalPilot workspace. From there, you can add a new database connection by selecting the database type you’d like to connect.

Each connection guide will walk you through:

What information you’ll need (host, port, username, password, etc.).

How to configure and test your connection in SignalPilot.

Best practices for security and connection management.

Once connected, your database will be available inside SignalPilot so you can easily query, analyze, and manage your data.
